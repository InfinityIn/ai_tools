- `README.md` → индекс всех **45** регламентов с кодами R0.1…R7.5 из §4, колонки:

## Критерий готовности (проверяется ревьюером командами, не словами)
1. `docs/regulations/README.md` содержит 45 строк с кодами R0.1–R7.5; `ls docs/regulations/R*.md | wc -l` = 45.
2. Каждый из 18 уроков памяти найден grep'ом по ключевой фразе ровно в одном файле `R*.md`;
   в файле памяти есть строка «закреплено: ai_tools R-…».
3. `grep -rl "Нужно от вас" src/ ~/.claude/skills/` → ровно 1 файл (`orchestrate`).
4. `ls ~/.claude/skills/ | grep -c sdlc` = 0; `ls src/references/sdlc/*.md | wc -l` = 15;
   ни один из них не содержит слов «оркестратор»/«субагент» в разделе процесса.
5. `templates/project-day0/`: `python scripts/day0_check.py` на шаблоне выходит с кодом 1
   и печатает 27 незакрытых пунктов; после отметки всех — код 0 (доказано мутацией).
6. `wc -l templates/project-day0/CLAUDE.md` ≤ 60.
7. villas: `grep -c "ai_tools" CLAUDE.md` ≥ 1, `grep -c "правило нуля" CLAUDE.md` = 0.
8. Финал сессии — 4 блока с метрикой: перенесено уроков / удалено копий / создано stub'ов.
