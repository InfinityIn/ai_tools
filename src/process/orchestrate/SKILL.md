# orchestrate — базовый процесс сессии-оркестратора

Любая задача решается за одну сессию, без компакта и без остановок. Сессия —
руководитель, агенты — исполнители, владелец может отойти.

## Роли

- **Оркестратор (эта сессия) — руководит, не исполняет.** Ставит задачи агентам,
  принимает результат, решает, фиксирует. Сам не читает большие файлы, логи и
  выдачу поиска, не пишет код, не копает данные.
- **Агенты — младшие модели (не выше Opus)**: чтение, поиск, код, действия.
  Возвращают выжимку с выводами; большие результаты кладут в файлы и отдают путь.

## Скелет процесса

1. **Постановка** — цель, критерий готовности, границы (что решает только
   владелец). Здесь же оценка влезаемости: не помещается в одну сессию —
   сразу резать на сессии, а не обнаруживать это на переполнении контекста.
2. **Разведка** — факты собирают агенты; оркестратор получает выжимки.
3. **Итерации** — задача → исполнение агентом → приёмка оркестратором.
   Этапы последовательно; параллельно — только явно независимое.
4. **Независимая проверка** — другой агент и/или другой метод, не автор.
5. **Фиксация** — артефакты в репо/на доску, обновить память, финал по стандарту.

## Принципы

- **Контекст оркестратора — бюджет.** Всё тяжёлое — через агентов и файлы.
  Дошли до компакта — процесс построен неправильно.
- **Не останавливаться.** Блокировка только на owner-решениях: деньги,
  безопасность, необратимое. Остальное — решить самому и задекларировать в финале.
- Побочные находки — отдельными карточками/задачами, не расширением текущей.

## Финал (и любая вынужденная остановка) — ровно 4 блока

Кратко, жирными пунктами, со ссылками (коммиты, карточки, URL). Без прозы.

1. **Нужно от вас** — действия/решения владельца (или «ничего»).
2. **Сделано** — пункты 1-2-3 со ссылками.
3. **Решил за вас** — решения, принятые чтобы не ждать.
4. **Осталось** — хвосты и следующий шаг (или «ничего»).
