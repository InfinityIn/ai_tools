# analyze-it — аналитика руками агентов

**База:** вызови скилл `orchestrate` и работай по его скелету. Правила работы с
данными (двойной пересчёт, вывод без цифры, доказательство первопричины) —
см. `orchestrate`, раздел «Анализ данных»; формат финала — там же.

## Профильные правила

- Аналитическая сессия **целиком** идёт в режиме «анализ данных» базы: это не
  один из этапов, а весь контур работы.
- Вопрос фиксируется до запросов: на какой вопрос отвечаем, какой ответ
  считается ответом, какая популяция и какой период.
- Найденное «надо починить» уходит карточкой в `develop-it`, а не правкой
  по ходу: аналитическая сессия ничего не чинит.

## Артефакт

Отчёт в `.claude/notes/<тема>/` по структуре из базы: выводы с цифрами →
запросы/методика в приложении → непроверенное.

## Регламенты

Каталог и индекс: `docs/regulations/README.md` в репозитории ai_tools
(https://github.com/InfinityIn/ai_tools). Ссылки — по коду.

- **R1.1** — Definition of Ready: задача входит в работу только с замером
  (число, популяция, дата, место); аналитика такой замер и производит.
- **R6.2** — телеметрия: на границах и только под SLO; чего нет в телеметрии,
  того нельзя померить.
