# Единая структура репозиториев

Все репозитории следуют одному скелету:

```
README.md — что это и как этим пользоваться
docs/     — документация и конвенции
scripts/  — служебные скрипты (установка, обслуживание)
data/     — данные
src/      — полезная нагрузка, код по папкам
```

Дополнительные соглашения:

- Креды проекта — в repo-root `.secrets/` (заносится в `.gitignore` **до** появления
  файлов, в git не попадает никогда).
- Проектные заметки и артефакты AI-сессий — `.claude/notes/<тема>/` внутри репозитория,
  не во временных каталогах.
