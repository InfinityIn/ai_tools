# R2.1 — Принципы архитектуры класса проектов

## Назначение

Принципы архитектуры класса проектов. Уровень A. Обязателен на день 0.

## Границы

- **Решает:** 12 принципов (конструкция вместо текста, одна истина + генерация, тип в БД, видимый отказ, одна точка записи, явное состояние, один путь конфига, флаг с датой смерти, телеметрия только под SLO, алерт = работа, безусловный гейт, фикс закрывает класс); каждый — с автопроверкой.
- **Не решает:** не решает архитектуру конкретного проекта.

все П1–П6 корневых причин потока багов.
