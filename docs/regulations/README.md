# Регламенты

Правила, общие для всех проектов владельца. Регламент отвечает на вопрос
«как это делается у нас» и живёт дольше любой фичи и любого репозитория.

Отличие от конвенций рядом (`docs/repo-structure.md`): конвенция описывает
форму, регламент — процесс и критерии.

| Регламент | О чём | Что фиксирует жёстко |
|---|---|---|
| [testing-pyramid.md](testing-pyramid.md) | пирамида тестов | любое изменение поведения требует красного теста на самой высокой видимой точке; живой ярус — только при синтетической личности; ярус, который не может покраснеть, — не ярус |

## Как регламент попадает в проект

Ссылкой из `CLAUDE.md` проекта, не копией: копии расходятся молча.
Раскладка, специфичная для проекта (какие ярусы заведены, чем запускаются,
чего осознанно нет), пишется в `docs/testing.md` самого проекта и ссылается
на регламент, а не пересказывает его.
