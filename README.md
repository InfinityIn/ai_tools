# AI Tools

Инструменты для работы с AI: скиллы Claude Code, выработанные на реальных проектах.

## Структура

```
docs/     — документация и конвенции
scripts/  — установка и обслуживание
data/     — данные
src/      — полезная нагрузка, код по папкам
```

- `docs/regulations/` — регламенты: правила, общие для всех проектов;
- `src/skills/` — универсальные скиллы;
- `src/process/` — семейство сессий-оркестраторов: база + профильные процессы.

## Семейство process: сессия руководит, агенты исполняют

Идея: любая задача решается за одну сессию, без переполнения контекста и без
остановок — сессия оркестрирует, младшие агенты читают/ищут/пишут код, владелец
может отойти. Финал всегда в 4 блоках: **нужно от вас / сделано / решил за вас /
осталось**.

| Скилл | Процесс | Ключевое |
|---|---|---|
| `orchestrate` | база для всех | роли, скелет 5 этапов, контекст-бюджет, стандарт финала |
| `develop-it` | разработка | worktree + TDD, независимое ревью с мутациями, мерж = деплой, live-приёмка |
| `research-it` | ресерч внешнего мира | многоканальный сбор вслепую, факт = ≥2 источника, адвокат дьявола |
| `collect-it` | сбор/закачка данных | схема до сбора, чанки с чекпойнтами, сверка с источником |
| `analyze-it` | аналитика по данным | read-only, каждая цифра дважды, вывод без цифры не существует |
| `experiment-it` | эксперименты/PoC | критерий фальсификации до опыта, песочница, бинарный вердикт, эстафета |

## Универсальные скиллы

| Скилл | Что делает |
|---|---|
| `brainstorm` | Безжалостное интервью по плану или решению: вопросы по одному, по веткам дерева решений, с рекомендацией к каждому. Факты скилл ищет в окружении сам, решения оставляет вам. |

`develop-it` опубликован в обезличенном виде: раздел «Ловушки проекта» — шаблон,
заполните его граблями своего проекта.

## Установка

Скиллы копируются в `~/.claude/skills/` (перезаписывая одноимённые):

```bash
scripts/install.sh
```

```powershell
scripts/install.ps1
```

После установки в Claude Code доступны команды `/brainstorm`, `/develop-it`,
`/research-it`, `/collect-it`, `/analyze-it`, `/experiment-it` (и `/orchestrate`
для нетипового процесса).
