# Template «день 0»

Скелет нового проекта владельца: конституция, чек-лист дня 0 и безусловный гейт, который
красный, пока день 0 не пройден.

Как сделать из него новый проект:

1. Скопировать содержимое каталога в пустой репозиторий (`.github/`, `.claude/` и точечные
   файлы тоже) и сделать первый коммит.
2. Заменить `<project>` в `CLAUDE.md` и `DAY0.md` на имя проекта, дописать принцип проекта.
3. Создать `.secrets/` вручную — каталог в git не попадает (он уже в `.gitignore`).
4. Идти по [DAY0.md](DAY0.md) сверху вниз; `python scripts/day0_check.py` показывает, что
   осталось, и держит CI красным до конца.
5. День 0 закрывается сквозной функцией в проде, а не галочками — критерий в `DAY0.md`.

Регламенты, на которые всё это ссылается, живут в
[ai_tools/docs/regulations](https://github.com/InfinityIn/ai_tools/blob/main/docs/regulations/README.md).
